# Changelog

Launcher versions, newest first. Dates are the day each version was committed to the launcher source. Only
versions with a clear change are listed, so some numbers are missing.

## 0.2.x

- **0.2.50** (15 Nov 2026) Reset my save data on the Account tab, with a plain warning at the top of the card.
- **0.2.48** (15 Nov 2026) Play stays off until a Dauntless Revived transfer is ready, with a retry button. The launcher updates itself when it is too old.
- **0.2.47** (15 Nov 2026) A refused game folder gets a clear message and a download button.
- **0.2.46** (15 Nov 2026) The transfer screen says that Escalation progress moves; only store purchases and cooldowns do not.
- **0.2.44** (9 Nov 2026) Logs the kind of network failure, 10 and 20 second timeouts with one retry, and asks you to locate a missing game.
- **0.2.43** (9 Nov 2026) Rebuilt for the play.afterlifeinteractive.com hosts.
- **0.2.42** (9 Nov 2026) First-run theme picker, crash context and opt-in crash dumps.
- **0.2.40** (8 Nov 2026) Build planner: repeaters with their live cell slots.
- **0.2.38** (8 Nov 2026) Removes a leftover chat port from the game config so chat connects and friend requests arrive.
- **0.2.37** (8 Nov 2026) Removes the UI scale setting and resets any stored scale to 100% at startup.
- **0.2.36** (8 Nov 2026) Find builds takes 6 target perks and marks legendary weapons.
- **0.2.35** (7 Nov 2026) Log upload works better on slow connections, and a Windows crash report is added.
- **0.2.34** (6 Nov 2026) Game language setting, plainer About wording and a Help and support link.
- **0.2.33** (6 Nov 2026) Build planner data fixes: Combiner is 1.12 only, Stunning Vigour is Defence.
- **0.2.32** (6 Nov 2026) Build planner game version switch.
- **0.2.30** (6 Nov 2026) Uninstall button.
- **0.2.29** (6 Nov 2026) Sahvyt theme.
- **0.2.28** (6 Nov 2026) No browser right-click menu or browser shortcuts in the launcher.
- **0.2.27** (6 Nov 2026) Play comes back on its own when the game closes.
- **0.2.25** (5 Nov 2026) Dauntless Revived link checks quietly while the save is fetched, a clearer not-found message, and a key file picker and paste.
- **0.2.24** (5 Nov 2026) Builds tab (perk and cell build planner, works offline) and six new themes: Drask, Kharabak, Embermane, Phaelanx, Riftstalker and Valomyr.
- **0.2.22** (2 Nov 2026) Online save download for offline mode, and a clearer message for a Dauntless Revived game copy.
- **0.2.21** (2 Nov 2026) Follows the https redirect to the game archive host again.
- **0.2.20** (1 Nov 2026) Updated security-patched dependencies.
- **0.2.18** (1 Nov 2026) Security hardening: tighter capabilities, https-only region checks and release endpoints, and a per-install device id.
- **0.2.17** (1 Nov 2026) Pangar theme (called Frostbite in the code).
- **0.2.16** (1 Nov 2026) The first-launch theme picker fits the window and scrolls.
- **0.2.15** (31 Oct 2026) Cleans leftover game config that points at another launcher's proxy by IP address.
- **0.2.12** (31 Oct 2026) Load your online save into offline mode. Offline processes end with the launcher.
- **0.2.9** (31 Oct 2026) Playtime card and hour badges on the Account tab.
- **0.2.8** (30 Oct 2026) Offline mode, and a quiet automatic region reporter.
- **0.2.7** (29 Oct 2026) Status banner, channel choice, quiet retry, minimise on Play and centred status boxes.
- **0.2.6** (24 Oct 2026) Offers to keep or replace when the account already has progress.
- **0.2.4** (24 Oct 2026) Asks the server about a Dauntless Revived account before every Play, and shows Afterlife Interactive in About.
- **0.2.2** (23 Oct 2026) Plainer wording and a soft fade between tabs.
- **0.2.1** (23 Oct 2026) Players pick their theme on first launch, and the disclaimer names Forte Labs too.
- **0.2.0** (23 Oct 2026) New look with four art themes and the dragon icon.
